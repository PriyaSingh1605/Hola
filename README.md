# Hola 💬  
A Real-Time Chat Application

Hola is a real-time online chatting website built using the **MERN stack (MongoDB, Express, React, Node.js)**.  
It allows users to sign up, log in, manage profiles, and communicate instantly through **Socket.io–based real-time messaging**.

---

## 🚀 Features

- 🔐 User Authentication (Signup / Login)
- 👤 User Profile Management
- 💬 Real-time one-to-one messaging
- ⚡ Socket.io integration for instant communication
- 📱 Responsive UI (works on desktop & mobile)
- 🗂️ MongoDB database for storing users & chats

---

## 🛠️ Tech Stack

**Frontend:**
- React.js
- Axios
- Tailwind CSS / CSS (if used)

**Backend:**
